Frequently Asked Questions

Find answers to basic questions regarding how the Extractor operates.

Does it collect or store my design data?

Absolutely not. The Design System Extractor parses local webpage document objects entirely within your local Chrome browser container. It does not send extracted colors, fonts, or assets to any analytical or remote server environments.

How do I download SVG vectors?

Once you extract a webpage, navigate to the "Assets" tab. Find any SVG layout listed and click the "Download SVG" button to immediately obtain the raw file, or copy it directly as inline SVG code.

Does it support password-protected pages?

Yes. Because the extension runs in your browser context after the page has finished loading, it can read style rules and layout parameters of any page you currently have active access to, including local host environments.
