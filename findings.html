UX Findings

Findings, teardowns and notes from designing and building things.

  • Bring Undo to more web interactions

    Muscle memory already knows Ctrl + Z, so give it something to reverse

  • Don't move the page while I'm reading

    If something loads in above you, correct the scroll by exactly its height

  • Don't make humans prove they are human

    Read the signals already there, and only interrupt when the answer is genuinely unclear

  • Slow doesn't always mean broken

    Let the message grow with the wait, so a slow load never reads as a dead one

  • Prevent duplicate actions

    Answer the press instantly and lock the button, so nobody pays twice

  • Retry only what failed

    One tile failed, so reload that tile, not the whole dashboard

  • Reduce uncertainty before the click

    Continue to what? Name the step the button leads to, before it is pressed

  • Make transitions preserve context

    The card the user clicked should be the thing that opens, not a screen that replaces it

  • Don’t just say “No results”

    Read the query, name what blocked it, and offer the one change that recovers it

  • Remember where the user left

    Come back to the field that was still empty, not to the top of the form

  • Learn repeated actions

    Three of the ten edited the same way, so offer to finish the other seven

  • Detect when the user is struggling

    Typed, cleared, typed again, so offer the hint before they go looking for help

  • Learn from repeated actions

    Drop the confirmation once the user is clearly cleaning up, and offer undo instead

  • Convert currency in place

    Put the converted amount in the selection menu, where the amount already is

  • Start loading on hover

    Prefetch on hover, so the click lands on a page that is already there

  • Let users start typing

    Remove the extra click before typing
